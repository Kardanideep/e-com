# MERN E-Commerce Project

## Overview
This is a full-stack e-commerce application built using the MERN (MongoDB, Express, React, Node.js) stack. The application provides users with a seamless shopping experience, featuring user authentication, a product catalog, a shopping cart, and secure checkout functionality.

---

## Features
- **User Authentication**: Secure user login and registration with JWT.
- **Product Management**: View, add, edit, and delete products.
- **Shopping Cart**: Add and manage products in the cart.
- **Order Management**: Place orders with a secure payment gateway.
- **Admin Dashboard**: Manage products, orders, and users.
- **Responsive Design**: Optimized for all devices.

---

## Tech Stack
- **Frontend**: React.js, Redux, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JSON Web Tokens (JWT)
- **Payment Integration**: Stripe/PayPal
- **Styling**: Custom CSS, Bootstrap
